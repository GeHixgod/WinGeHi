# 🚀 GeHi Windows 11 Optimizer

> A modern, transparent, and safe script for optimizing and tweaking Windows 11. Fully localized in English and Ukrainian. No closed-source third-party bloatware — total control over your system via PowerShell.

---

## ✨ Features

* **🛠 Full Transparency:** The entire code is open, so you know exactly what changes are being made to your system.
* **🌐 Multilingual:** Built-in support for English and Ukrainian languages in the interactive console interface.
* **🎮 Gaming Tweaks:** Maximum FPS and reduced input lag (MPO adjustments, `SystemResponsiveness`, GPU scheduler, disabling memory compression).
* **🔒 Privacy & Security:** Disabling unnecessary telemetry, ads, Copilot, Recall, and background services with the option to create a restore point and registry backups.

---

## 📥 Quick Start (One-Click)

To run the optimizer directly from GitHub, open **PowerShell** as **Administrator** and execute the following command:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; irm https://raw.githubusercontent.com/GeHixgod/GeHi-Win11-Optimizer/refs/heads/main/GeHi_Optimizer.ps1 | iex 
```

# 🚀 GeHi Windows 11 Optimizer

> Сучасний, прозорий та безпечний скрипт для оптимізації та налаштування Windows 11. Повністю локалізований українською та англійською мовами. Жодних сторонніх закритих програм — повний контроль над вашою системою через PowerShell.

## ✨ Особливості проєкту

* **🛠 Повна прозорість:** Весь код відкритий, ви точно знаєте, які зміни вносяться в систему.
* **🌐 Багатомовність:** Зручний інтерактивний інтерфейс із повною підтримкою української та англійської мов.

* **🔒 Безпека та конфіденційність:** Вимкнення зайвої телеметрії, реклами, Copilot, Recall та непотрібних фонових служб із можливістю створення точки відновлення та резервних копій реєстру.
